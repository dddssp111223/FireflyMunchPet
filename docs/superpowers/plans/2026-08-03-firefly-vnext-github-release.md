# Firefly MunchPet v7 GitHub 发布实施计划

1. 从远端最新 `master` 创建隔离发布分支并提交已确认的发布规格。
2. 将验收通过的流萤最终版源码、场景、素材、测试和打包脚本同步到分支。
3. 先增加公开发布契约测试，确认旧 README 和脸颊拉伸残留会触发失败。
4. 清理未使用的脸颊代码、测试和素材，更新 README 与 v7 Release Notes。
5. 运行 Python、.NET、Godot/OpenGL、提醒原生窗口、回收站和 ZIP 验证。
6. 审计 Git 变更、单文件大小、敏感信息和发布排除项。
7. 提交、同步远端、推送并合并到 `master`，创建 `v7` 标签和 GitHub Release。
8. 上传免安装 ZIP，远端复核标签、说明、资产大小和 SHA-256。

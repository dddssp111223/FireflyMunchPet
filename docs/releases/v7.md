# Firefly MunchPet v7

这是流萤桌宠经过完整视觉迭代后的公开版本。

## 新增与改进

- 重做眼睛分层：原图虹膜不再残留，左右虹膜独立并在眼眶范围内跟随鼠标。
- 文件悬停使用独立、固定的星星眼关键帧，不再摇晃或脉动。
- 完整投喂动画：文件图标飞入口中、张嘴咬下、`><` 闭眼吞咽和明显回弹。
- Q 弹以画面底部为锚点向下压缩，松开后平滑复位。
- 新增“和谐版”，去除嘴部口水和桌面水迹，并记住用户选择。
- 缩放档位扩展为 30%、50%、75%、100%、125% 和 150%。
- 新增提醒备忘录：最多 5 项、每项 200 字，支持定时/倒数、一次性/循环、
  启用/停用、编辑和删除。
- 提醒编辑器改为独立窗口；触发时显示薄荷绿透明气泡，并以 1 秒间隔执行
  两次 Q 弹和音效。
- 修复透明窗口、桌面接缝、非 100% 缩放裁切和提醒气泡黑框问题。
- 移除视觉效果未达标的脸颊拉伸交互及其过期源码/素材。
